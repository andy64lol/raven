# Raven
Este es un jueguito que hicimos pa un game jam
corre el main.py y ya está xd

cómo usarlo:
```
git clone https://github.com/andy64lol/raven.git
cd raven
pip install -r requirements.txt
python main.py
```

todo eso asumiendo que usas python en vez de python3, no necesitas un venv o --break-system-packages ni nada así
